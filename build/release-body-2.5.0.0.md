# LitheMD 2.5.0.0

本版本是阅读器修复版，不包含编辑功能。

## 调整

- 大括号改为“四段 1/4 圆弧 + 两段粗竖线”：圆弧靠近竖线一端较粗，向尖端和中间收细；修正最上下两段圆弧的方向。
- 调色盘“新建”立即增加颜色并生效；新增“删除”按钮，至少保留 1 个颜色。
- 主栏颜色可取消勾选并重新补满；备选颜色最多 12 个，主栏最多 5 个。
- 调色盘和导出窗口在深色模式下使用深色标题栏。
- 调色盘左上角改用应用图标；RGB/十六进制输入框随深浅主题切换。
- 修复设置窗口偶发打开崩溃：滚动条可见性更新移到 Canvas BeginDraw 之前。
- 修复图片和 PDF 的左右滑动：处理触摸板/横向滚轮发送的 `WM_MOUSEHWHEEL`。
- 修复鼠标拖动滚动卡顿：滚动条/滚轮走轻量位置更新，中键拖动在鼠标移动路径补帧。
- 版本号更新为 2.5.0.0。

## 说明

- 编辑功能推迟至 2.6.0.0；本版本不包含编辑入口，编辑内核未参与编译。
- Windows 10 1903+ / Windows 11，64 位，无需安装运行库。
