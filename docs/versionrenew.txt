LitheMD 版本更新记录
====================

2.4.1.2  (2026-11-21)
---------------------
调整
- 工具栏和欢迎页的“打开”合并为下拉按钮：打开文件 / 打开文件夹；`Ctrl+O` 和 `Ctrl+Shift+O` 仍直接执行。
- 右上角“文件”按钮改为工作区菜单：打开文件夹、显示/隐藏工作区、刷新工作区。
- 欢迎页在最近文件下新增“最近工作区”，最多显示 3 个，可清空。
安全
- 新增二进制特判名单，在读取和解码前拒绝：
  `.exe .dll .sys .drv .scr .com .msi .msp .cpl .ocx .efi .bin .lnk .class .pyc .o .obj .lib`。
- 命令行、拖放、路径输入、最近记录和 ZIP 条目预览统一经过该特判。
修复
- 切换到已打开标签时，如果用户取消保存笔记，不再错误重载当前标签。

2.4.1.1  (2026-11-21)
---------------------
安全修复
- ZIP 解压校验所有条目（包括文件夹条目），修复恶意目录条目可穿越目标目录的问题。
- 解压前统一检查目标路径是否位于用户选择的目标文件夹内，兼容盘符根目录。
- Deflate 解压改为带 512 MB 上限的流式回调，避免伪造压缩大小导致超大内存分配。

修复
- 工作区根目录为 `C:\` 或其他带尾部分隔符路径时，活动文件定位和路径包含判断失效。
- 工作区刷新后保留已展开的文件夹。
- ZIP 条目预览不会在打开失败时误改当前标签标题。

- 新增 MIT LICENSE，并保留第三方组件原有许可证。
调整

- 明确 `build.ps1` 为唯一构建脚本，`build.bat` 仅为资源管理器双击包装器。
- 补充 `samples/` 示例文件与 README/第三方说明的一致性。
修复
- 阅读位置记录最多保留 500 个文档，避免配置文件无限增长。

2.3.0.0  (2026-11-19)
---------------------
重命名
- 项目正式更名为 LitheMD，发布文件改为 `dist/lithemd.exe`；首次启动自动把旧的 `%LOCALAPPDATA%\openmd` 配置、最近记录和笔记迁移到 `%LOCALAPPDATA%\lithemd`。
新增
- 画笔选择支持整体平移，移动、缩放、旋转按组合整体生效。
- 组合功能修复：选中对象始终扩展为完整组；组擦除同步删除整组；拆组清除整组关系；复制/粘贴保留组结构；组合/拆组按钮按状态启用。
- 画笔颜色改为最多 12 个预设色，左侧“新建”保存当前颜色；可选择最多 5 个颜色显示在主栏；右击主栏色点或预设色可替换颜色。
- 调色盘重做：HSV 取色区、色相/透明度滑块、RGB/十六进制输入、棋盘格预览和“确定/取消”；旧 `customColor1/2` 自动迁移。
- 主栏固定“选择”和“板擦”并移到最左侧，不参与隐藏；两者使用自绘矢量图标。
- 荧光笔对有文本层的 Markdown/Word/纯文本等按文字范围高亮，并绘制在文字下方；PDF 文字层保留半透明文字高亮；无文字层格式回退自由笔迹。
- 设置 → 外观新增蓝白、深色、暖纸、护眼四种主题，默认蓝白；配置新增 `themeId`，兼容旧 `theme`。
- 导出新增 PDF；PNG 与 PDF 均支持 A4 分页和单张长页/长图，支持 150/300 DPI；PDF 为位图 PDF，不包含可搜索文字。
调整
- 移除画笔选择栏的“保存”按钮，保留顶部全局保存和 `Ctrl+S`。
- 修复超大文件导出预览卡顿：过大、过长或生成超时直接显示“文件过大，不支持预览”。
修复
- 半透明画笔/荧光笔改为单条连续路径绘制，不再在每个采样点叠加圆点，避免轨迹中出现串珠状圆形重叠。
- 设置页四个主题按钮与滚轮速度控件分区布局，修复控件重叠。

2.2.2.0  (2026-11-18)
---------------------
新增
- 画笔新增“选择”工具：以一条笔迹/一个图形/一段文字为单位选择，支持点击、Shift 多选、框内拖动移动、四角缩放、旋转柄旋转。
- 选择工具新增套索圈选：按住拖动绘制虚线轨迹，松开后自动连接起点与终点；完全落在圈选区域内的笔迹、图形和文字一起被选中，组合对象仍按整组处理。
- 选择后可复制、粘贴、组合、取消组合、删除；组合后点击组内任一对象会选中整组。
- 荧光笔扩展到所有可注释格式：PDF 保留文字感知高亮；Markdown、Word、表格、图片、文本/源码等格式使用半透明荧光笔迹，并随每文档笔记保存/加载。
- 源码视图支持自动换行：`.cpp` 等纯文本源码在窗口宽度或缩放变化时重新排版，行号只显示在逻辑行首，长行不再依赖横向滚动。
- 每文档笔记文件：保存在 `config.json` 同目录的 `lithemd-notes/<路径哈希>.json`，自动加载，**不自动保存**。
- `Ctrl+S` 或顶部“保存”按钮保存当前文档笔记；关闭标签/刷新/退出时若有未保存笔记会提示“保存 / 不保存 / 取消”。
- PDF 文字荧光笔：拖动框选文字后高亮；扫描版 PDF 无文字层时退化为矩形荧光笔；高亮随笔记一起保存/加载。
- 快捷键新增 `保存笔记`、`粘贴笔迹`、`组合笔迹`、`取消组合`、`删除笔迹`、`荧光笔`，全部可在设置 → 快捷键中修改。
- 笔记 JSON 保存笔画、图形、文字、颜色、宽度、组合编号、旋转角度、荧光笔标记、PDF 高亮；使用临时文件原子替换。

优化
- 顶部“保存”按钮在普通阅读模式下也常驻显示，不再只在画笔模式出现。
- 没有可保存文档或没有未保存修改时，顶部“保存”和画笔选区栏“保存”会禁用并以半透明灰显显示；`Ctrl+S` 同步无效，避免无意义操作或报错。
- 窗口变窄时按优先级收起源码/缩放/大纲等次要按钮，保留保存/编码/主题/设置，避免头部控件重叠；并增加最小窗口尺寸。
- 选区操作栏新增“旋转”按钮（每次 15°），同时保留旋转手柄。
- 构建默认对全部源文件使用 `-O2`；遇到 GCC 的偶发 ICE 先重试 `-O2`，再尝试关闭基本块重排的 `-O2`，最后才降级到 `-O1`/`-O0`。构建失败不再删除上一版 `dist`。

修复
- 修复 `\sum\limits_{...}` 中 `\limits` 被跳过时吞掉后续 `_`/`^` 的问题，求和上下限恢复正确位置。
- 修复数学公式中逗号与斜体字母重叠、逗号后间距丢失的问题；`\left(...\right)` 不再吞掉括号。
- 修复 2.2.1.0 中 `shortcuts` 写回 config 时值被重复加引号的问题。
- 刷新文档时保留当前未保存的画笔和 PDF 高亮，避免自动重载丢失。
- 输入框获得焦点时，全局快捷键优先让位给文字编辑。

2.2.0.0  (2026-11-18)
---------------------
新增
- 文本编码自动识别：默认 UTF-8；有效 UTF-8 始终优先，只有 UTF-8 非法时才尝试传统编码。
- 支持 UTF-8（含 BOM）、UTF-16 LE/BE（含无 BOM 启发式）、UTF-32 LE/BE、GB18030/GBK、Big5、Shift-JIS、EUC-KR、Windows-1252/1251/1250、Latin-1 以及系统 ANSI 代码页。
- 顶部新增“编码”菜单：可查看当前编码、手动切换编码、重新检测编码，并在解码失败时给出明确提示。
- 新增文档语言选项：自动 / 简体中文 / 繁体中文 / 日语 / 韩语 / 西文；语言作为编码识别提示，并写入 config.json 的 `documentLanguage`。
- 新增乱码检测与修复：识别 UTF-8 被误按单字节编码解析等常见乱码，逐行尝试反向恢复；状态栏显示“已修复乱码”，菜单提供“尝试修复乱码”。

优化
- 英文/西文短文本不再被误判为中文或韩文编码；Windows-1251 保留为手动选项，避免抢占中文/西文识别。
- 编码识别采用常用字频率、脚本文本比例和编码先验评分，兼顾简体、繁体、日文、韩文和西文。
- `common.cpp` 在 GCC 16.2 下采用 `-O1`/`-O0` 降级编译，避开 `-O2` 编译器 ICE。

2.1.1.1  (2026-11-15)
---------------------
新增
- 画笔注释支持文字工具：点击画布输入文字，Enter 确认、Esc 取消，文字随文档滚动和缩放。
- 画笔注释支持几何图形：直线、箭头、矩形、椭圆，拖动即可绘制。
- 表头单元格支持复制：Markdown 表格表头、CSV/Excel 表格表头均可悬停复制。
- 数学公式支持 `\bigcap`、`\bigcup`、`\bigvee`、`\bigwedge` 等大型运算符及上下限。
- 修复数学渲染：`\mid` 不再显示成文字 “mid”；`\not\mid`、`\not\equiv` 等否定关系正常显示。
- 修复 `\lfloor`、`\rfloor` 以及 `\left\lfloor...\right\rfloor` 的取整括号渲染。
- 修复 `\bmod` 两侧间距，`a\bmod m` 不再粘连。
- 修复深色模式下侧边和底部滚动条仍显示白色底色的问题，滚动条现在跟随深色主题。
- 主页“最近打开”改为内嵌滚动列表，按 8 条分批加载，最多保留 500 条；滑到底部显示加载完成提示，主页本身不再产生滚动条。
- 画笔工具条增加“更多”隐藏栏，不常用工具可收起；默认主工具条显示笔、擦、线、框、字，箭和圆放入隐藏栏。
- 设置窗口新增画笔工具按钮勾选，可调整每个工具放在主工具条还是隐藏栏；配置新增 `inkToolsVisible` 位掩码。
- 设置窗口新增“复制配置”，可直接把 config.json 内容复制到剪贴板。

修复
- 修复 `arenlist.json` 中 `\left|\bigcap_{i\in S}B_i\right|` 被显示成 “bigcap” 的问题。该公式本身合法，问题在渲染器未识别 `\bigcap`。
- 确认绝对值竖线本身可正常显示；此前观感上的轻微倾斜来自字体抗锯齿，实际为竖直字形的放大误差。
- 修复 LaTeX 左右定界符画反：矩阵括号、`\left( ... \right)` 等左括号显示成右括号、右括号显示成左括号。
- 修复对话记录气泡组间距应用位置错误：新消息组紧贴上一组、卡片背景几乎相接；现在跨组间距加在组前，组内头与正文保持紧凑。
- 修复 Markdown 表格分列时把公式或行内代码中的竖线当成分隔符的问题，`(r-|S|)^n` 等内容不再被截断。
- 文字注释读取输入内容时使用固定缓冲区，避免个别系统下 `GetWindowTextLength` 返回异常。
- 构建脚本将 LaTeX 渲染器固定为 `-O1`，避开当前 GCC 在 `-O2` 下误编译造成的公式页面无响应。
- 新增 `docs/annotations-export-plan.md`，分析旁注保存、图片/PDF 导出和打印的可行性与实施顺序。

2.1.1  (2026-11-15)
-------------------
新增
- 画笔注释：以当前文档为画布，直接在正文、表格、源码、PDF 和图片上书写。
- 画笔工具条：画笔 / 橡皮、6 种颜色、粗细调节、撤销、清空、完成。
- 注释随文档滚动移动；切换标签页后每个文件保留自己的注释。
- Markdown 预览/源码、JSON、表格和 PDF 分别保留独立注释层，切换视图不会互相串位。
- 图片使用归一化坐标保存注释，缩放或调整窗口后仍贴合图片。
- `Ctrl+Shift+A` 打开/关闭画笔，`Ctrl+Z` 撤销，`Esc` 退出画笔。

实现说明
- 注释数据保存在当前标签页内，不修改原文件；关闭标签页后注释释放。
- CSV/Excel 按工作表分别保存注释；切换工作表不会把注释画到别的工作表上。

2.1.0  (2026-11-15)
-------------------
新增
- 多文件标签页：可同时打开多个文档，点击标签切换，关闭当前文件回到主页。
- 主页标签：关闭最后一个文件后自动回到主页。
- 图片查看：支持 PNG / JPEG / GIF / BMP / TIFF / ICO / WebP，按窗口适配并支持缩放。
- 未知格式按纯文本打开。
- 鼠标中键快速滑动：按住中键后，光标离按下点越远，页面沿光标方向滚动越快。
- 代码块与表格单元格悬停时显示复制按钮，点击即可复制内容。
- 渲染视图支持“预览 / 源码”切换，覆盖 Markdown、JSON、Notebook、对话记录和表格等格式。
- 设置中的格式复选列表：可勾选要注册到“打开方式”的文件格式；顶部“全选”勾选框可一键全选或全不选，全部勾选时自动选中。
- “加入打开方式”会注册应用本身，让 Windows 的“打开方式”和“默认应用”识别 LitheMD；选中扩展名时同时完成格式注册。
- 支持取消选中格式的注册，并提供 Windows 默认应用权限设置入口。
- 清空本地数据：删除配置、最近记录和相关本地缓存，不删除用户文件。
- docs/versionrenew.txt 版本记录。

修复与优化
- 修复旧版 .doc 文档解析异常时可能导致崩溃的问题，增加解析异常保护和长度上限。
- 修复对话记录中消息气泡间距过小、相互遮挡的问题。
- 支持把内容实际为 OpenCode 会话 JSON 的 .md 文件识别为对话记录。
- 移除主页和设置页中面向开发者的 .NET / 离线实现说明，改为面向用户的文案。
- PDF 引擎改为内嵌 PDFium，避免系统 PDF 接口在不同环境下的兼容性问题。
- 图片、PDF、表格和源码视图的状态栏信息更清晰。
- 修复复制按钮的“已复制”打勾状态在移动到其他单元格或代码块后仍然残留的问题。
- 复制按钮改为半透明浮层（按下状态不高于 60% 不透明度），并确保始终绘制在正文之上、点击优先命中。
- 强化 CSV / Excel 表格的列宽、行高拖动：鼠标移到分隔线时显示缩放光标和高亮线，并扩大可拖动范围；表头保持固定。
